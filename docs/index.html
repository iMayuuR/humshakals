HONEST BY DESIGN

Beautiful previews.
Clear boundaries.

A realistic frame is useful for QA—but it is not a physical operating system.

WHAT IT DOES

See and test responsive behavior fast.

  • Chromium webviews sized to configured content viewports
  • Device-like browser chrome, rotation and keyboard simulation
  • Playwright against visible screens and supported Android Chrome
  • Optional agent inspection with bounded actions
WHAT IT DOES NOT CLAIM

It does not turn a laptop into an iPhone.

  • iPhone frames are not native iOS Safari sessions
  • Simulated UI cannot reproduce every OS-only bug
  • Imported Git, npm and MCP code is not sandboxed
  • Real-device sign-off still needs real hardware
◇

CONTROLLED, NOT MYSTERIOUS

Know what runs. Know what leaves.

Sites stay in isolated webviews. Git tests and MCP servers require trust because they execute as your OS user. AI requests may include page evidence sent to the chosen provider. New saved API/VPN secrets require OS-backed encryption; private evidence stays local until you export it.

GOOD QUESTIONS

Before you dive in.

The practical answers behind the polished frame.

Can Humshakals run real iOS or Android?

Its built-in phone frames are browser-engine simulations, not iOS or Android OS sessions. Supported physical Android devices can be connected for real Chrome automation. iOS-specific issues still need an iPhone or a separately configured native device runner.

Will my existing Playwright tests open a separate browser?

The Automation Lab runs selected layout targets against visible Humshakals webviews, with their effective viewports. A trusted imported repository can bring its own dependencies and configuration; review them before execution. Supported connected Android devices run in real Chrome.

Does the Browser Agent automatically get every permission?

No. Choose its target screens and provider. Browser actions are bounded, and external MCP tools require separate connection and per-call approval. Never connect an untrusted server or send private staging content to a provider without checking your policy.

Can I download a production-ready installer today?

Not yet. Public installers will follow signing, dependency scanning and packaged-platform QA. This page showcases the app while those release checks are completed.
